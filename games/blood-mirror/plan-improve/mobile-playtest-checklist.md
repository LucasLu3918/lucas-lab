# 鏡淵 E1–E5 手機真機試玩檢查清單

- 日期：2026-10-14
- 目的：補上目前唯一沒做過的驗證——**真實手指**。所有自動化與瀏覽器測試都是合成事件，無法回答「拖得動嗎、點得到嗎、看得懂嗎」。
- 預估時間：每關 15–25 分鐘，五關約 1.5–2 小時；建議分兩次。

## 0. 準備

- [ ] 用預覽網址或正式站，在**手機瀏覽器**開 `/games/blood-mirror/play/`（不要用桌面縮小視窗）。
- [ ] 至少兩台：一台窄螢幕（寬 ≤ 360 px）、一台一般（約 390 px）；有平板或橫向也各試一次。
- [ ] 存檔：先通關任一結局（首頁才會出現「帳本的背面」），或匯入已有結局的存檔。
- [ ] 記下機型、瀏覽器、系統版本、是否開「減少動態」。
- [ ] 開聲音一次、靜音一次（確認機關提示不靠聲音）。

## 1. 每一關都要看的共通項目

| # | 檢查 | 通過標準 |
|---|---|---|
| C1 | 點擊目標 | 所有按鈕、格子一次點得到，不誤觸旁邊的 |
| C2 | 版面 | 沒有橫向捲動、沒有被截斷的文字或按鈕；彈窗內可上下捲動 |
| C3 | 捲動與手勢 | 拖曳機關時頁面不會跟著捲、不會觸發下拉重新整理或返回手勢 |
| C4 | 回饋 | 做錯有一句說明；做對有明顯變化；不靠顏色也看得出差別 |
| C5 | 提示 | 「燭光提示」三層依序出現，第三層看得懂答案；闔上再開仍正常 |
| C6 | 中斷 | 做到一半關掉彈窗／切到別的 App 再回來，已完成的機關還在 |
| C7 | 存檔 | 完成後重新整理，該關顯示「已完成」；首頁進度 x / 5 頁正確 |
| C8 | 重玩 | 已完成的關卡按「再玩一次」能玩，結束後有提示且進度不變 |
| C9 | 讀得懂 | 不看說明，能說出「這一步要做什麼」 |
| C10 | 計時 | 記下每道機關耗時與卡住的位置（企劃估 E1–E4 各 12–25 分、E5 20–25 分） |

## 2. E1 逆走鐘樓（齒輪、擺錘、星輪）

- [ ] 齒輪列：點軸座、從托盤選齒輪，點得準嗎？軸座直徑約 67 px，是否仍會點錯鄰近軸座？
- [ ] 齒輪放上去後的齒數標籤是否讀得清（小字）？
- [ ] 「轉動曲柄 13 圈」動畫流暢；減少動態時直接完成。
- [ ] 擺錘：掛上／取下重物的點擊範圍；節奏與刻痕是否看得懂。
- [ ] 星輪：轉動的操作方式清楚；鐘響次數與刻痕對得上。
- [ ] 三道機關的先後（齒輪與擺錘可任一先做，星輪要等兩者）是否被看懂。
- [ ] 解封畫面看到「ㄎ」，記得這是之後密碼要用的記號嗎？

## 3. E2 稜鏡舞廳（濾鏡、合光水晶、舞廳）

- [ ] 光路上的旋轉／切換控制，手指一次轉一格嗎？
- [ ] 紅、綠、藍三色**不靠顏色**也能分辨（形狀或文字）。
- [ ] 合光水晶的選色與結果預覽，色盲模擬或自己觀察是否仍可解。
- [ ] 舞廳機關要等前兩者完成；等待說明看得懂。
- [ ] 解封看到「ㄒ」。

## 4. E3 毒蘋果調配室（證詞、量杯、調色）

- [ ] 七人證詞：卡片文字（每句 ≤ 80 字）在手機上不用縮放就讀得完；劃掉記事本好操作。
- [ ] 量杯倒入：點哪杯倒向哪杯很清楚；步驟能復原。
- [ ] 調色：用方向詞與形狀記號，**不靠顏色**也能比對。
- [ ] 解封看到「ㄋ」。

## 5. E4 無限鏡廊（疊放、大小、翻面、排序）— 風險最高

- [ ] **拖曳整格畫面**：手指拖得動；拖動時頁面不捲動。
- [ ] 吸附：放開時偏約 10–15 px 仍會吸到對的物件（窄版板面縮到約 0.23–0.4 倍）。
- [ ] 點一格放大到板面寬；其餘三格變成下方圖磚，圖磚高度約 44 px，一次點得到、拖得出來。
- [ ] 拖出圖磚時它在手指下恢復原尺寸；以格子中心當把手是否順手（沒有「抓著物件本身」的拖法）。
- [ ] 翻面按鈕、放大按鈕 ≥ 44 px；門上的金色小三角看得出開口方向。
- [ ] 「用清單放置」可以完全取代拖曳（選擇器在手機上好用嗎）。
- [ ] 排序：點卡片放入四格，點已放的格子可取消。
- [ ] 解封看到「ㄧ」。
- [ ] **作者決定**：門上金色小三角保留，還是請模型重畫有門把的門？

## 6. E5 七重魔鏡匣

- [ ] 選單：六面縮圖與狀態文字（尚未完成／還缺少需要的物品／要先完成前面的機關）看得懂。
- [ ] **缺關卡測試**：只做完部分 E1–E4，進 E5：被鎖的面是否說明要回哪一關。
- [ ] 時辰面：十三格圓盤的格子（窄版約 36 px）點得準嗎？−、＋、「扣上」是否足夠備援。
- [ ] 光之面：舉起稜鏡看得到刻線；五個顏色鈕（含形狀）好按；按滿三個才判定這件事看得懂。
- [ ] 蘋果鎖：要先選蘋果再按「滴入回魂藥」，流程不會被忽略。
- [ ] 鏡中鏡：四格依序點選；縮圖大小夠辨識。
- [ ] 碎片面：先點碎片再點位置；缺碎片時位置標「缺：幕名」看得懂。
- [ ] 密碼盤：**最可能卡關**。
  - [ ] 注音順序表（4 排）在窄版不橫向溢出、字夠大。
  - [ ] 玩家能理解「往回數」嗎？記下需要看到第幾層提示才懂。
  - [ ] −5／−1／＋1／＋5 與「直接選格數」下拉哪個更常用？下拉選單在手機上好選嗎？
- [ ] 結局：七幕碎片齊全顯示完整結局與字條；少碎片顯示縮減結局（可用另一份存檔）。
- [ ] **整關重玩**：六面依序走完；每面之間只停頓約 0.3 秒，不會覺得被打斷。

## 7. 要帶回來的資料

1. 機型與瀏覽器、螢幕寬度。
2. 每道機關耗時、第一次卡住的位置、用到的提示層數。
3. 點錯、拖不動、看不清的**具體畫面**（截圖或錄影）。
4. 「看不懂要做什麼」的地方，用你自己的話描述。
5. 嚴重度：**擋關**（做不下去）／**麻煩**（做得下去但煩）／**小瑕疵**。
6. 是否要調整：E4 窄版板面、E5 撥盤格子大小、密碼盤的引導、各關耗時。

## 8. 已知風險（試玩時特別留意）

- E4：窄版（280 px）板面只有約 0.23 倍，物件標記很小，靠 22 px 吸附。
- E5：十三格撥盤格子偏小；密碼盤概念門檻高。
- 美術未經作者驗收：E5 碎片面畫成八片、密碼盤上是偽字符。
- 其餘約 7 個瀏覽器套件在 E5 合併前沒有重跑。
