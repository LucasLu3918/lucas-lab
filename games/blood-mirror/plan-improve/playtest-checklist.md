# 鏡淵·下卷 真人試玩檢查表

- 範圍：E-X 影戲小屋、E6 失聲合唱廳、E7 稱量廳、E8 凝結的三刻、E9 魔鏡羅盤、小結尾「最後一頁」。
- 目的：補上目前完全沒有的驗證——真人手機操作、難度與時長、美術驗收、從清單一路點入的完整流程。
- 建議：至少 3 位試玩者，至少 1 位用手機（直式）、1 位用電腦；其中至少 1 位沒看過任何解答。試玩者**不要**先看本表最後的「主持人解答」。

## 0. 試玩前準備（主持人）

- [ ] 用正式網站或本機預覽，開在乾淨的瀏覽器分頁（無痕視窗最乾淨，不要沿用開發用存檔）。
- [ ] 鏡淵入口要「看過任一結局」才會出現；若想直接測鏡淵，先請試玩者走完一個結局，或匯入已有結局的存檔。
- [ ] 準備計時（每關開始到完成）與一份空白紀錄（見第 7 節）。
- [ ] 手機測試：直式，記下機型與瀏覽器；另外各用一次「減少動態」開啟與關閉。
- [ ] 規則：試玩者卡住超過 5 分鐘才允許用燭光提示；記下何時、第幾層提示才解開。

## 1. 共通檢查（每一關都看）

- [ ] 進入：從首頁的鏡淵入口進清單，點該關，看完開場，按進入鈕，能開始。
- [ ] 讀得懂：開場文字、規則說明（第一次看就知道要做什麼嗎？）
- [ ] 觸控：所有按鈕、選單用手指點得準，不會點錯鄰近的；不需要放大。
- [ ] 版面：390 寬直式下沒有橫向捲動、文字沒有被切掉、圖形沒有重疊。
- [ ] 回饋：答錯時回饋看得懂，但**不會直接洩漏答案**。
- [ ] 提示：三層提示每一層都有幫助；第三層確實能解開。
- [ ] 完成：完成時有明顯回應；解封畫面與獎勵正確；回到清單後該關顯示「已完成」。
- [ ] 重玩：已完成的關卡可以再玩，且不改動進度。
- [ ] 中途離開：玩到一半關閉視窗再回來，行為合理（不壞掉、已完成的道仍保留）。
- [ ] 色盲與靜音：不靠顏色或聲音也能玩（本批沒有用聲音；顏色都另有形狀或文字）。

## 2. 各關檢查

### E-X 影戲小屋（預期 8–10 分，難度 0.50）
- [ ] 兩個滑桿：拖曳與鍵盤方向鍵都能操作，每步 5 度。
- [ ] 牆上剪影與目標是否容易比對？「對齊」的判定感覺公平嗎（太鬆或太緊）？
- [ ] 第二道（戴冠的女人）要等第一道完成；鎖住時的說明看得懂。
- [ ] 問：有沒有「明明對齊了卻不過」或「還沒對齊就過了」？

### E6 失聲合唱廳（預期 12–15 分，難度 0.70）
- [ ] 管長與音高成反比：試玩者是否在沒提示下理解？（陷阱組：長 8、10、12。）
- [ ] 三個聲部的起拍：是否看得懂「每 3、4、6 拍」疊成樂譜？
- [ ] 聖歌（第三道）：需要前兩道的結果；試玩者是否知道要回頭翻？
- [ ] 全程無聲：是否有人期待有聲音？對此失望或覺得是特色？

### E7 稱量廳（預期 14–18 分，難度 0.80）
- [ ] 帳頁上的等式是否看得懂（沒有數字，只有符號與鐵砝碼）？
- [ ] 加減鈕的操作是否順手；右盤符號是否太小。
- [ ] 最後一台要用前兩頁的重量；「翻回前兩頁帳頁」摺疊是否被發現？
- [ ] 回饋只說「天秤沒有平衡」：試玩者會不會因此覺得不公平？

### E8 凝結的三刻（預期 15–20 分，難度 0.88）
- [ ] 向量賓客：面具形狀、顏色、袖口在手機上能分辨嗎？（特別看金色與紅色、白袖與黑袖。）
- [ ] 第一道暖身（兩人）是否讓人懂得玩法？
- [ ] 第二道三張畫：「每一刻只換一對位置」的規則是否看得懂？
- [ ] 第三道：是否有人照畫框的掛法（甲乙丙）直接填而答錯？答錯後能想通嗎？
- [ ] 歧義：任何一條記憶是否被讀成兩種意思？（記下原話。）
- [ ] 回饋只說「第 k 條記憶說不通」：夠用嗎？

### E9 魔鏡羅盤（預期 15–20 分，難度 0.92）
- [ ] 規則「轉一環一格，相鄰環反向轉兩格」：試玩者多久才理解？
- [ ] 8 個按鈕（每環一對順逆時針）在手機上好按嗎；環上的記號文字在轉動時是否保持可讀。
- [ ] 步數上限與「齒輪卡死、退回起點」：感覺是挫折還是挑戰？是否有人因此放棄？
- [ ] 「回到起點」鈕是否被發現、是否有用。
- [ ] 需要完成前四關：未完成時的說明是否清楚指出缺哪一關。
- [ ] 三道（內圈、外圈、四環）難度階梯是否合理；第三道是否比兩道相加更難。

### 小結尾「最後一頁」
- [ ] 完成 E9 後，鏡淵清單底部出現這一頁；E9 未完成時**不出現**。
- [ ] 兩個選項都試一次：回應、收尾、稱號都正確；返回鈕可回清單。
- [ ] 稱號「被帳冊記住的人」顯示在收藏分頁。
- [ ] 讀後感：是否讀成「世界想起了白雪」（不應該）？是否覺得與原著結局衝突？（記下原話，這是敘事風險點。）

## 3. 整條流程（至少一位試玩者完整走一次）

- [ ] 從首頁鏡淵入口 → E-X → E6 → E7 → E8（順序可自選）→ E9 → 最後一頁。
- [ ] 進度顯示「已翻開 n / 9 頁」是否隨完成更新。
- [ ] 關閉瀏覽器重開，進度、稱號都在。
- [ ] 全程總時長（預期 64–83 分鐘）。

## 4. 美術驗收（作者）

- [ ] E-X、E6、E7、E8、E9 的橫幅是否符合各關氣氛、與既有 E1–E5 風格一致。
- [ ] 橫幅裡的內容是否與謎題矛盾（例如 E8 橫幅的人數與謎題不同——這是已知，只確認不會誤導）。
- [ ] 縮圖在清單上是否好認。
- [ ] E8 向量賓客的風格是否可接受（與橫幅的寫實風格落差）。

## 5. 要在手機上特別確認的事

- [ ] 直式 390 寬；橫式也快速看一次。
- [ ] 彈出視窗內捲動順暢，按鈕不被瀏覽器網址列或手勢遮住。
- [ ] 連點按鈕不會重複觸發或卡死。
- [ ] 系統設定「減少動態」開啟時，E9 與其他關卡仍可玩（本批沒有動畫迴圈）。

## 6. 通過標準（建議）

- 每關至少 2/3 的試玩者在不用第三層提示下完成。
- 每關實際時長落在預期的 0.5 到 2 倍之內；超出就調整規則或提示。
- 沒有任何一位試玩者遇到「操作做不到」（只能放棄）的情形。
- 沒有未解的歧義回報。
- 小結尾沒有人讀出與原著結局衝突的意思。
