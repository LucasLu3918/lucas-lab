# 共用 UI 與故事封面實作計畫

## 目標與方法

延續使用者已選定的「夜幕藍黑、古金、酒紅、月光奇幻」方向，讓全站使用相同元件材質、尺寸與互動規則。所有七部故事都使用原創封面，書名由 HTML 排版，避免圖片內中文字失真。

維持 Node 靜態產頁、原生 CSS／JavaScript 架構。現有規模適合共用產頁函式與 CSS tokens；本次不需要新增前端框架、UI 套件、付費 API 或外部圖床。若未來有會員、雲端書籤或大量內容編輯需求，再評估獨立的資料與 CMS 架構。

## 實作順序與依賴

1. **盤點與基準**：確認全部頁面家族、元件、七本書及既有素材；擷取修改前手機、平板與桌面證據。
2. **封面製作**：以既有白雪公主封面為風格基準，產生其餘六本的原創插畫；檢視主題、人物、光影與裁切。
3. **共用元件**：建立 `scripts/components.cjs`；將既有疊加 CSS 整理為單一設計系統，統一圖示、按鈕、狀態、輸入、面板與書籍展示。
4. **全站接入**：套用首頁、館藏、工具、遊戲、作品集、藝廊、日誌、關於、授權、搜尋、404 及所有閱讀章節。
5. **閱讀與素材體驗**：章節下拉選單、即時本章進度、字體上下限狀態；封面加入藝廊，支援原生彈窗預覽與 Esc。
6. **驗證與交付**：內容 checksum、建置、BASE_PATH 路徑、responsive 圖像、320–1440px 頁面、鍵盤／觸控、無障礙及人工像素檢視。

## 元件盤點與規則

| 元件 | 共用來源／類別 | 規則 |
| --- | --- | --- |
| 導覽、圖示按鈕 | `.header`、`.nav`、`icon()` | 本機線條 SVG，選取狀態不改變尺寸，920px 以下折疊 |
| 主次按鈕 | `button()`、`.btn` | 48px 高、6px 圓角；主按鈕酒紅、次按鈕深色；hover／focus／disabled 明確 |
| 狀態標籤 | `badge()`、`.status-*` | 依完整／示範／概念等語意配色，以文字提供辨識 |
| 搜尋、篩選、選單 | `.search`、`.filter`、`select` | 搜尋 48px、篩選至少 44px；小螢幕篩選列可捲動 |
| 一般卡片、工具、分類入口 | `.card`、`.tool`、`.cat` | 共用面板、細古金邊框、10px 圓角與陰影 |
| 書籍封面與卡片 | `cover()`、`media()`、`.book-art` | 完整 2:3 插畫；館藏直式、首頁／搜尋緊湊圖文，保持書名可讀 |
| 內容提示、空狀態 | `notice()`、`.warning`、`.empty` | 共用邊框與排版；清楚文字與圖示，不依賴顏色 |
| 章節列表、閱讀控制 | `readerControls()`、`.chapterlist` | 共用狀態規則；正文紙張模式為閱讀舒適度的語意例外 |
| 藝廊與彈窗 | `.gallery`、`.dialog` | 封面可放大，原生 dialog 處理焦點與 Esc，完整圖像不裁掉人物 |
| 標題、內文、麵包屑、頁尾 | `--font-display`／`--font-body` | 襯線標題、清楚無襯線控制文字，統一間距與可見焦點 |

元件展示頁：`/style-guide/`，不放入 sitemap 或主要導覽；可用於設計／維護時檢視。

## 素材與效能

- 每本書：900×1350 完整封面 + 360×540 小封面，均為 WebP。
- 使用 `srcset`／`sizes`、圖片尺寸宣告與 lazy-loading；首頁主視覺及精選封面依需求優先載入。
- 完整封面預算 260 KB／張，小封面 60 KB／張；目前所有封面符合。
- `COVER_ASSETS.json` 記錄路徑、尺寸、檔案大小、hash 及來源；不保存完整生成提示。
- 書籍詳情加入封面 Open Graph metadata，改善分享預覽。

## 驗收與適用限制

- 六份正式原稿 checksum、全部章節與原有內容狀態維持正確。
- 所有七本書的封面皆可解碼，來源與顯示比例 2:3；館藏、詳情、搜尋、首頁與藝廊都能呈現。
- 代表頁面在 320、360、390、480、720、768、900、1024、1440px 無意外橫向溢位。
- 搜尋／篩選、選單、章節切換、字體上下限、閱讀進度與彈窗可操作；選取狀態不跳動。
- WCAG axe 檢查與人工截圖檢視；Chromium 模擬不能代替真實 iOS Safari／Android 裝置驗收。
