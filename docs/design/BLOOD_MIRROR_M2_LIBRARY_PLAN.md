## 二、黑鐘書庫目標流程

核心體驗：**身份與契約——拼回被撕毀的證據，親手讀到自己的出生代價。**

```
醒來（短開場，只交代處境）
 → 探索：懷錶（收取）、鐘塔手札（得出 13）、被撕碎的出生紀錄（數字與簽名缺損）
 → 證據操作：拼回出生紀錄碎片（取代肖像拼圖）→ 顯現 73 與簽名欄
 → 封印：依懷錶規則輸入 1373
 → 場景後果：暗門開啟，新熱點「王室契約」出現
 → 故事揭露：檢視契約時才揭曉「父親的簽名」，收入隨身物品
 → 前往下一幕
```

設計要點：
- **每一層各有作用。**拼圖負責「復原證據」，密碼負責「推理組合」。兩層都和故事有關，也各有不同的操作。
- **答案只能從遊玩中取得。**序章刪除具體數字；73 只出現在修復後的出生紀錄。
- **揭露放在後果之後。**簽名從序章與出生紀錄移到解鎖後的契約熱點。
- **不需要新的美術資產。**碎片可用 SVG／CSS 排版的文件紙張呈現（文字由介面排版，符合方向 14）。正式紙張材質之後在 M5 替換。

### 批次 2：黑鐘書庫樣板

**WC-03 開場精簡**（方向 02、08｜S）
- 修改：`openStory` 刪除「第十三下」「七十三」「父親的簽名」三個具體資訊，只保留王國背景與「妳也在帳簿上」的懸念。`begin()` 的第一幕視窗改成一句處境加一個行動（「看看桌上的懷錶」），並由「下一步」引導帶到懷錶熱點。
- 預期感受：30 秒內進入場景，第一次點擊就有發現。
- 驗收：新手不看遊玩指南也能開始探索並收取懷錶。
- 存檔影響：無（純文字）。**需要確認改編尺度（決策 Q1）。**

**WC-04 證據修復拼圖（整合雙層封印）**（方向 04、03｜M）
- 修改：
  - `challenges.js` 的 library 分支改為「拼回出生紀錄」：沿用 3×3 交換機制、鍵盤操作與重新打散，圖塊改為 SVG 文件碎片；完成後的整頁顯示「抵押七十三名兒童」與空白簽名欄。
  - 拼圖改由「檢視出生紀錄熱點」開啟，不再由封印觸發。
  - `engine.js` 的 `birth.text` 改成撕碎前的殘句；修復後的全文成為新的筆記條目。
  - `bells` 改為只提供「十三」（例如以十二座鐘塔與第十三聲推得），不再重複懷錶的順序規則。
- 封印前置條件：`openPuzzle` 對 library 只要求懷錶，以及「出生紀錄已修復」（沿用 `isChallengeComplete('library')`）。
- 驗收：沒有修復紀錄就無法從任何文字得知 73；拼圖完成後，筆記與下一步引導會更新；手機與鍵盤都能完成。
- 存檔影響：不變更 `blood-mirror-challenges-v2` 格式。舊存檔中 `library` 已完成即視為已修復。

**WC-05 解封後的場景後果與揭露**（方向 03、07、15｜M）
- 修改：
  - 熱點新增 `after:'solved'` 欄位（只在本幕解開後顯示），第一幕加入「暗門後的王室契約」熱點。

- 預期感受：「我解開了某樣東西，世界因此改變，然後我自己讀到真相。」
- 驗收：解開後出現新熱點；下一步引導先指向契約，再指向下一幕；`chooseEnding` 與其他幕不受影響。

## 七、M3 五幕推廣與單人遊玩保障（2026-10-10）

第一幕的「證據操作 → 封印推理 → 場景後果 → 揭露」已套用到其餘四幕。所有互動謎題都改從證據熱點開啟；證據修復前，封印只會顯示引導（`evidenceGate`），不會讓玩家盲猜。

| --- | --- | --- | --- | --- |

**單人遊玩保障**
- 每一幕的「下一步建議」都能一路帶到結局。`blood-mirror-solo.test.mjs` 模擬只按建議的玩家，確認五幕都能通關、三個結局都能取得、所有熱點都被引導到。
- 每一幕都有三段提示；必要物品不會藏在解封後才出現的熱點裡；最後一幕沒有會阻擋選擇的後續內容。
- 玻璃棺的記憶題提供放慢速度、播放時以文字逐一報出符印名稱，答錯兩次後可查看棺蓋刻痕，不依賴短期記憶也能通過。
- 鏡像題顯示「已映照 n / 4 列」，每一格都向輔助技術報出亮或暗。
- 設定中新增「單人試玩紀錄」：預設關閉，只存在本機，可以下載 JSON，關閉時刪除。這讓沒有測試夥伴時也能取得每一幕的耗時、答錯次數與提示層級（見試玩基線包第 5 節）。

**存檔**：格式不變。已解開的幕一律視為證據已修復；舊存檔中已完成的互動謎題也視為已修復。新的後續熱點會出現在已解開的幕中，可以補看，不影響進度。

**驗證**：單元測試 29 項；瀏覽器測試涵蓋完整旅程（390／1280px，含刻痕輔助）、管線（360–1280px）、UI（360–1440px）、單人試玩紀錄（360／1280px，確認沒有任何對外網路請求）、藝廊與配樂。
