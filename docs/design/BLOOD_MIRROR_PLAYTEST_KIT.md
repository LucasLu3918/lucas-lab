# 《血色魔鏡》試玩基線包（WC-01）

日期：2026-10-10｜用途：取得 M2 前後的真人比較資料（優化方向 01、21）。不使用遙測，不蒐集姓名以外的個資；紀錄以代號保存。

## 1. 試玩對象與場次

| 組別 | 人數 | 條件 | 主要觀察 |
| --- | --- | --- | --- |
| 新手 | 3 | 少玩密室或解謎遊戲，未接觸本作 | 開場理解、操作發現、卡關與提示使用 |
| 熟手 | 2 | 常玩解謎／敘事遊戲，未接觸本作 | 謎題公平性、推理樂趣、重複感 |
| 裝置 | — | 至少 2 人用手機（iOS Safari 或 Android Chrome），其餘用桌面 | 觸控命中、視窗與閱讀負擔 |

5 人足以找出多數嚴重問題。M2 驗收只需完成**第一幕**（約 10–15 分鐘）；有時間的人可以繼續玩，額外紀錄留給 M3 參考。

## 2. 主持流程（每場約 25 分鐘）

1. **說明（1 分鐘）**：只說「這是一款網頁解謎遊戲，請邊玩邊說出想法；我測的是遊戲，不是你」。不介紹玩法，也不提到提示按鈕。
2. **遊玩（10–15 分鐘）**：用清除過資料的瀏覽器，從首頁開始。主持人只觀察和記錄，不提供協助。玩家卡住超過 3 分鐘、且沒有使用遊戲內提示時，可以問「你現在想做什麼？」，但不給答案。
3. **訪談（5 分鐘）**：依序問第 4 節的問題。
4. **整理（3 分鐘）**：主持人當場填完紀錄表的評分欄。

## 4. 訪談問題

1. 用一句話說說，你在第一幕扮演誰？要做什麼？
2. 1373 這組密碼是怎麼得出來的？
3. 拼回帳頁這一步，你覺得它有什麼作用？（判斷雙層封印是否成立）
4. 哪一刻最讓你有感覺？哪一刻最無聊或最困惑？
5. 1–5 分：你有多想繼續玩下一幕？為什麼？

## 5. 單人自測流程（沒有主持人或其他玩家時）

這款遊戲本身就是單人遊玩。自測的困難在於：自己知道答案，難以觀察自己。以下流程用來降低這個偏差：

1. **開啟紀錄**：設定 →「單人試玩紀錄」→ 開啟。紀錄只存在這個瀏覽器，不會上傳；關閉時會一併刪除。
2. **冷啟動**：使用無痕視窗或另一個瀏覽器，從首頁開始。上次修改後至少隔一天再玩，並且不要先看規劃文件。
3. **限制自己**：卡住時只能使用遊戲內的「下一步建議」與「提示」，不能查原始碼或文件。這正是單人玩家實際擁有的資源。
4. **邊玩邊記**：在第 3 節紀錄表旁另開一份筆記，記下每次「不確定下一步」的時間點與原因。
5. **匯出比較**：通關後在設定中「下載 JSON」，存成 `playlog-日期-SHA.json`。設定中的摘要表列出每一幕的耗時、修復證據時間、答錯次數與最高提示層級，可直接填入第 3 節。
6. **判讀**：某一幕提示用到第 3 層，或答錯 3 次以上，就列為待改善。只要真人資料一出現，就以真人資料為準。

自動檢查的部分由 `scripts/blood-mirror-solo.test.mjs` 負責：它模擬一位只按「下一步建議」的玩家，確認五幕都能通關、三個結局都能取得，而且每一幕的關鍵資訊都在修復證據後才出現。

## 6. 判定標準（M2 驗收）

| 指標 | 通過 |
| --- | --- |
| 不看指南就能開始探索 | ≥ 4 / 5 人 |
| 能說出任務與身份（問題 1） | ≥ 4 / 5 人 |
| 能解釋密碼來源（問題 2），不只是看了第 3 段提示 | ≥ 3 / 5 人 |
| 認為拼回帳頁和故事或密碼有關（問題 3） | ≥ 3 / 5 人；否則重新檢討雙層封印 |
| 注意到暗門熱點並讀到契約 | ≥ 4 / 5 人 |
| 想繼續玩（問題 5 ≥ 4 分） | 先記錄基線，不預設目標 |

結果記錄在本檔最後的「紀錄」一節，或另建 `BLOOD_MIRROR_PLAYTEST_LOG.md`。每一輪標註當時的提交 SHA，方便比較修改前後的差異。
